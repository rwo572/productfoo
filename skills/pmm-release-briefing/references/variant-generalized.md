# PMM release briefing outline

Use this only as a local draft shape. It grants no connector access, schedule,
or delivery authority.

## Sections

1. Release and audience
2. What changed
3. Customer impact
4. Evidence and confidence
5. Risks, unknowns, and dissent
6. Owners and proposed next actions
7. Sources used, sources omitted, trust status, and limits

The human reviews the completed outline and performs any external delivery.
