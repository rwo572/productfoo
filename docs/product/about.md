# About productfoo

productfoo is a personal open-source project for working with coding agents.
It helps turn an idea into an agreed spec, keep decisions and evidence together,
and compare implementation with the work that was agreed.

The name comes from `foo`, the placeholder programmers use while figuring out
what something should become. The command is still `foo`.

The project is shared for people who find the approach useful. Contributions and
forks are welcome under Apache-2.0. There is no commercial service commitment,
guaranteed roadmap, or support schedule.

productfoo is unaffiliated with and not endorsed by any current or former employer.
Read [project status and responsible use](../../README.md#project-status-and-responsible-use)
before using it with an agent or private data.
